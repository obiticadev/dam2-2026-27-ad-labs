# Librerías JAXB incluidas

JAXB 2 (`javax.xml.bind`) y sus dependencias están en esta carpeta para compilar el ejercicio con JDK 11 sin Maven.

- `jakarta.xml.bind-api-2.3.3.jar`: API JAXB 2, con paquete `javax.xml.bind`.
- `jaxb-runtime-2.3.8.jar`: implementación JAXB.
- `txw2-2.3.8.jar` y `istack-commons-runtime-3.0.12.jar`: dependencias del runtime.
- `javax.activation-api-1.2.0.jar` y `jakarta.activation-1.2.2.jar`: API e implementación de Activation usadas por JAXB.
